# Ollama release history

v1.0.0 (2026-10-29, first release): Local AI models through Ollama, as a plugin, built on SlideMage's plugin API 1: the Ollama provider for the chat, drafting and translation, and the Ollama tab of the Settings sheet (the server's address; update and delete of installed models).

v1.0.1 (2026-10-29, website icon): The plugin has its own icon on the SlideMage website and in the plugin list, a stylized llama head with an AI sparkle; the plugin itself is unchanged.
